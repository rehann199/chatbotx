# Privacy and Source

## Source code

The application source is private and is not included in this repository. This repository contains documentation, diagrams and screenshots only.

## Screenshots and data

- Screenshots are real captures of a local build, with no accounts or user data involved.
- All visible text is the product's own interface copy or fictional placeholder content. Contact details shown on the landing page are placeholders.
- Marketing figures on the landing page (for example response-time, accuracy, uptime and compliance wording) are placeholder copy and are not measured or certified results.

## Secrets and configuration

No secrets were found in the reviewed code. Any environment-specific configuration is excluded from this repository.

## Third-party components

Built on open-source libraries (React, Material UI, Redux Toolkit, Framer Motion, Socket.IO, FastAPI and others), each under its own licence. The Inter typeface is loaded from a public font host in the demo build. Names and trademarks belong to their owners.
